# دليل النشر الإنتاجي - Learning Tree Connect

## نظرة عامة

هذا الدليل يغطي جميع الخطوات المطلوبة لنشر منصة Learning Tree Connect في بيئة الإنتاج. المنصة مستضافة على بنية Manus التحتية مع دعم التوسع التلقائي (Autoscale) وشهادات SSL المجانية.

## خطوات النشر

### الخطوة الأولى: تنظيف قاعدة البيانات

قبل النشر، يجب إزالة جميع البيانات التجريبية. يمكنك تنفيذ ذلك من خلال واجهة قاعدة البيانات في لوحة الإدارة:

```sql
-- تنظيف البيانات التجريبية (بالترتيب الصحيح لتجنب مشاكل المفاتيح الخارجية)
DELETE FROM notifications;
DELETE FROM loyalty_transactions;
DELETE FROM loyalty_points;
DELETE FROM messages;
DELETE FROM conversations;
DELETE FROM invoices;
DELETE FROM daily_reports;
DELETE FROM attendance;
DELETE FROM children;
DELETE FROM users WHERE role != 'admin';
DELETE FROM loyalty_rewards;
```

> **تحذير:** هذا الأمر يحذف جميع البيانات نهائياً. تأكد من أخذ نسخة احتياطية إذا كانت هناك بيانات مهمة.

### الخطوة الثانية: تهيئة البيانات الأساسية

بعد التنظيف، قم بتشغيل سكربت الإعداد الإنتاجي لإنشاء كتالوج المكافآت:

```bash
npx tsx server/seed.ts
```

هذا السكربت ينشئ فقط:
- كتالوج مكافآت برنامج الولاء (5 مكافآت)

### الخطوة الثالثة: النشر عبر واجهة الإدارة

1. افتح واجهة الإدارة (Management UI)
2. تأكد من وجود نقطة تفتيش (Checkpoint) محفوظة
3. اضغط زر **Publish** في أعلى يمين الواجهة
4. انتظر حتى يكتمل النشر (عادة 2-5 دقائق)
5. تحقق من أن الحالة تظهر "Published" في لوحة Dashboard

### الخطوة الرابعة: ربط النطاق المخصص

اتبع الخطوات المفصلة في ملف `DNS-SETUP-GUIDE.md` المرفق لربط النطاق `portal.learningtreeco.com`.

### الخطوة الخامسة: التحقق بعد النشر

| الاختبار | الطريقة | النتيجة المتوقعة |
|----------|---------|-----------------|
| تحميل الصفحة | زيارة الرابط في المتصفح | ظهور صفحة تسجيل الدخول |
| تسجيل الدخول كمدير | تسجيل الدخول بحساب المالك | ظهور لوحة التحكم الكاملة |
| إضافة معلمة | من صفحة إدارة المستخدمين | نجاح الإضافة |
| إضافة ولي أمر | من صفحة إدارة المستخدمين | نجاح الإضافة |
| إضافة طفل | من صفحة الأطفال | نجاح الإضافة مع ربط ولي الأمر |
| رفع صورة | في التقرير اليومي | نجاح الرفع والعرض |
| شهادة SSL | التحقق من القفل الأخضر | شهادة صالحة |

## إعداد الحسابات الأولية

### حساب المدير (Admin)

حساب المدير يُنشأ تلقائياً عند أول تسجيل دخول من مالك المشروع عبر بوابة OAuth. لا يلزم إنشاؤه يدوياً.

### إضافة المعلمات

1. سجّل الدخول كمدير
2. اذهب إلى **إدارة المستخدمين** من القائمة الجانبية
3. اضغط **إضافة مستخدم**
4. اختر الدور: **معلمة**
5. أدخل الاسم والبريد الإلكتروني ورقم الهاتف
6. اضغط **حفظ**

### إضافة أولياء الأمور

نفس الخطوات أعلاه مع اختيار الدور: **ولي أمر**

### ربط الأطفال بأولياء الأمور

1. اذهب إلى صفحة **الأطفال**
2. اضغط **إضافة طفل**
3. أدخل بيانات الطفل واختر ولي الأمر من القائمة
4. اضغط **حفظ**

## المواصفات التقنية للبيئة الإنتاجية

| المواصفة | القيمة |
|----------|--------|
| وقت التشغيل | Node.js (Autoscale) |
| المعالج | 1 vCPU |
| الذاكرة | 512 MiB |
| مهلة الطلب | 180 ثانية |
| الحد الأدنى للنسخ | 0 (بدء بارد عند عدم النشاط) |

| SSL | تلقائي ومجاني |
| قاعدة البيانات | TiDB (متوافقة مع MySQL) |
| التخزين | S3 |

## متغيرات البيئة

جميع المتغيرات التالية تُدار تلقائياً من المنصة ولا تحتاج تعديلاً يدوياً:

| المتغير | الوصف |
|---------|-------|
| DATABASE_URL | رابط الاتصال بقاعدة البيانات |
| JWT_SECRET | مفتاح توقيع جلسات المستخدمين |
| VITE_APP_ID | معرف تطبيق OAuth |
| OAUTH_SERVER_URL | خادم مصادقة OAuth |
| BUILT_IN_FORGE_API_URL | واجهة برمجة التطبيقات الداخلية |
| BUILT_IN_FORGE_API_KEY | مفتاح الوصول للخدمات الداخلية |

## المراقبة والصيانة

### مراقبة الأداء

- **لوحة Dashboard:** تعرض إحصائيات الزيارات (UV/PV) في واجهة الإدارة
- **سجلات الأخطاء:** متاحة في مجلد `.manus-logs/` أثناء التطوير

### التحديثات

1. أجرِ التعديلات المطلوبة في الكود
2. شغّل الاختبارات: `pnpm test`
3. احفظ نقطة تفتيش جديدة
4. اضغط **Publish** لنشر التحديث

### وقت التوقف المتوقع

- التحديثات: صفر وقت توقف (نشر تدريجي)
- البدء البارد: 3-8 ثوانٍ بعد فترة عدم نشاط

## الدعم الفني

في حال واجهت مشاكل تقنية:

1. تحقق من سجلات الخادم في `.manus-logs/devserver.log`
2. تحقق من سجلات المتصفح في `.manus-logs/browserConsole.log`
3. تحقق من طلبات الشبكة في `.manus-logs/networkRequests.log`
4. راجع حالة الخدمات في لوحة Dashboard
